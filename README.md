- [FS/TI-92 ENO© Font (by MetrikEnzyme)](https://www.1001fonts.com/fs-ti-92-eno-c-font.html)
- [Pixel-AE (by Essssam)](https://essssam.itch.io/pixel-ae)
- [Ghoulam (by mloukhiyye)](https://mloukhiyye.itch.io/ghoulam-arabic-pixel-art-font-version-1)
- [Arabixel Basic (ArabianDev)](https://arabiandev.itch.io/arabixel-basic-font)
- [Arabixel Antique (ArabianDev)](https://arabiandev.itch.io/arabixel-antique-font)
